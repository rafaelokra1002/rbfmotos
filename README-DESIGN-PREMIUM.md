## 🎨 EXEMPLOS DE USO

### StatCard
```tsx
import { StatCard } from './ui/StatCard';
import { Wrench } from 'lucide-react';

<StatCard
  title="Ordens Abertas"
  value={12}
  icon={Wrench}
  color="blue"
  onClick={() => navigate('ordens')}
/>
```

### EmptyState
```tsx
import { EmptyState } from './ui/EmptyState';

<EmptyState
  title="Lista vazia"
  description="Adicione o primeiro item"
  action={{ label: 'Adicionar', onClick: add }}
/>
```

### Loading
```tsx
import { SkeletonCard } from './ui/Skeleton';

{loading ? <SkeletonCard /> : <MeuCard />}
```

## 🐛 TROUBLESHOOTING

### Cores não aparecem?
→ Verifique se design-tokens.css foi importado ANTES do index.css

### Componentes não encontrados?
→ Verifique se os arquivos estão em `src/components/ui/`

### Tailwind não reconhece classes?
→ Rode `npm run dev` novamente após alterar config
